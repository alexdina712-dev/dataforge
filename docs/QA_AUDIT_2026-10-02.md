# DataForge — QA audit, 2 October 2026

## Executed verification

- **77 unit/API tests passed** on the updated Desktop installation. DataForge includes 68 pytest and 9 Vitest tests.
- **18 Playwright scenarios passed**: six workflows on desktop, tablet and mobile Chromium.
- Strict TypeScript and production build passed. Python Ruff lint and formatting passed.
- Every browser scenario asserts that no uncaught JavaScript exception occurred.
- pnpm audit of runtime **and development** dependencies returned zero known advisories on this date. pip-audit also returned no known advisories for the pinned Python runtime/test requirements.

## Fixes and regression evidence

The browser suite has an isolated loopback test API/frontend on ports 8005/5186, including a separate test-only import budget. It no longer consumes the normal demo's rate quota or private sessions. The Windows Python invocation is quoted correctly. Production limits remain unchanged and have API coverage.

The initial expanded browser run correctly hit the normal import throttle. A fresh isolated test run then passed all 18 cases without relaxing production controls. Windows pytest used a unique --basetemp directory because the shared temporary directory had incompatible permissions.

Vitest was updated to patched version 4.1.11. 
The relevant upstream advisories are [Vitest](https://github.com/advisories/GHSA-82fw-gwwq-j7x9), [Effect](https://github.com/advisories/GHSA-38f7-945m-qr2g) and [deepmerge-ts](https://github.com/advisories/GHSA-ggr8-5vv4-36mx).

## Coverage and limits

The workflows exercise authentication/privacy, main create/edit/delete or status transitions, filtering, downloads and responsive navigation as applicable. InvoiceFlow tests verify real Unicode PDFs, 100-line pagination, authorization and totals. DataForge tests cover malformed files, macro/formula rejection, revisions, undo, exports and resource boundaries. CareerLens exercises real PDF/DOCX/TXT extraction and advisory analysis. OpsBoard exercises tenant permissions, project/task changes, comments and organization onboarding.

This is a reproducible portfolio QA pass, not a guarantee of no defects or an independent penetration test. Chromium device emulation does not establish Safari/Firefox compatibility or full accessibility compliance. Docker execution remains unverified where Docker is unavailable. Free hosting may sleep; no paid upgrade or artificial keepalive was introduced. Dependency scans are point-in-time checks.

## Reproduce

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm test:e2e
pnpm audit
```

For DataForge also run `python -m pytest`, `python -m ruff check backend` and `python -m ruff format --check backend`. On Windows with a shared-temp permission conflict, use a fresh `--basetemp .runtime/pytest-unique-name` directory.

Live deployment and CI verification are recorded separately after publishing the audited revision.
